# TungTungTung

This GitHub Pages site opens **https://sillypup.cfd/** immediately inside a fullscreen iframe, with no launch screen or button click.

**Website:** https://damonrosshutchins-boop.github.io/tungtungtung/

## Deploy

In the repository, open **Settings → Pages**, select **Deploy from a branch**, select **main** and **/(root)**, and save.

## Note

The target site must permit iframe embedding. If it sends `X-Frame-Options` or `Content-Security-Policy: frame-ancestors` headers that block third-party frames, GitHub Pages cannot override this.
